# Data and code availability draft

## Manuscript-ready wording

The de-identified trial-level ratings, analysis-ready data, data dictionary,
and Python code supporting the findings of this study are available in
[REPOSITORY] at [DOI OR PERSISTENT URL]. The deposited record contains the 500
AI-synthesized face stimuli, participant-wise correlation analyses, Fisher's z
group-level inference, GEE models, cross-classified mixed-effects models, and
code used to generate the reported statistical tables and figures. The stimulus
manifest provides the filename, dimensions, file size, and SHA-256 checksum for
each face image. The record also includes the image-derived facial-expression
features and code for the expression-adjusted robustness analyses; pretrained
third-party model weights are not redistributed.

## Code availability wording

All analysis code is available in [REPOSITORY] at [DOI OR PERSISTENT URL]. The
repository includes a pinned Python environment, validation checks, executable
scripts, and a notebook that reproduces the main analyses from the de-identified
trial-level data.
